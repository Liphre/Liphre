### 🧩 Projetos em destaque
- **Família Conectada — Sistema de Monitoramento Escolar**  
  Projeto acadêmico desenvolvido em Python com PyQt5 e MySQL, permitindo aos pais monitorar o desempenho escolar de seus filhos. Funcionalidades incluem:
  - Tela de Login e Registro
  - Visualização de Notas
  - Horários de Aula
  - Calendário de Atividades Escolares  

  O sistema se conecta a um banco de dados MySQL para armazenar e recuperar informações, com arquivo SQL de criação/inserção e modelo lógico para melhor visualização da estrutura do banco.  
  [Código](https://github.com/Liphre/Projeto-Extensao)

- **PSET 1 — Banco de Dados**  
  Exercício acadêmico de implementação de banco de dados usando SQL, Git e GitHub. O projeto inclui:  
  - Reconstrução das tabelas do modelo HR no SQL Power Architect, com comentários em cada atributo.  
  - Implementação prática no **PostgreSQL**, criando usuário, banco de dados `uvv`, schema `hr` e configurando permissões.  
  - Implementação equivalente no **MySQL**, com criação de usuário, database e concessão de privilégios.  
  - Scripts detalhados para SQL Power Architect (`cc1n_202200532_hr.architect`), PostgreSQL (`cc1n_202200532_postgresql_hr.sql`) e MySQL (`cc1n_202200532_mariadb_hr.sql`).  

  [Código](https://github.com/Liphre/uvv_bd_1_cc1n)
